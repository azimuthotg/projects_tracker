### 2. แคป screenshot ใหม่ทั้งหมดเป็น 16:9

สร้าง `docs/capture_screens.py` — ใช้ Playwright แคป 31 หน้าจออัตโนมัติ

- viewport 1600×900 เรนเดอร์ที่ scale 2 → ไฟล์ 3200×1800 (อัตราส่วน 1.7778 พอดีทุกไฟล์)
- ลองที่ 1920×1080 แล้วตัวอักษรในภาพเล็กเกินไปเมื่อพิมพ์ลงกระดาษ ลองที่ 1280×720 แล้วตารางกิจกรรมถูกตัดคอลัมน์ขวา จึงลงตัวที่ 1600×900
- เลื่อนหน้าจอโดยอ้างอิง selector ของหัวข้อจริง (`text=...`, `h3:has-text(...)`) แทนการนับพิกเซล เพื่อให้แคปซ้ำได้ผลเดิม
- ทั้งหมดเป็น GET อย่างเดียว ไม่แตะข้อมูล production

**การเข้าระบบ:** บัญชี `admin` ถูกตั้ง `is_active=False` ในฐานข้อมูล production จึงล็อกอินไม่ได้ และไม่ได้แก้ flag นี้ ใช้วิธีสร้าง session cookie ให้ `admin_e` ผ่าน settings ชั่วคราวที่ตั้ง `SESSION_ENGINE = signed_cookies` — ไม่มีการเขียนลงฐานข้อมูลจริงเลย

**3 ภาพที่ใช้ข้อมูลตัวอย่าง:** หน้ารออนุมัติ, หน้าตรวจสอบรายการเบิกจ่าย และประวัติการโอนงบ เพราะระบบจริงไม่มี expense สถานะ `pending` เหลืออยู่ (view กรอง `status='pending'` จึงคืน 404) และยังไม่เคยมีการโอนงบ จึง migrate SQLite แยกแล้ว seed ข้อมูลตัวอย่างเพื่อแคปเฉพาะ 3 ภาพนี้

### 3. เขียน `docs/build_manual_v2.py` ตามรูปแบบที่ผู้ใช้กำหนด

| ข้อกำหนด | วิธีทำ |
|---|---|
| ห้าม bullet | ไม่ใช้ style `List Bullet`/`List Number` เลย — `steps()` พิมพ์เลขลำดับเองในย่อหน้าธรรมดาพร้อม hanging indent; รายการแบบ "ชื่อ — คำอธิบาย" แปลงเป็นตาราง |
| ตัวหนังสือสีดำ | `thai()` ไม่กำหนดสีใด ๆ และ override Heading 1–3 ให้เป็น `000000` |
| หัวตารางจัดกลาง พื้นเทา | `table()` จัดกึ่งกลาง + shading `E7E7E7` เป็นสีเดียวในเอกสาร |
| ไม่มีคำแนะนำ/คำเตือน | ตัดฟังก์ชัน `note()` ทิ้ง เงื่อนไขของระบบเขียนเป็นข้อความปกติหรือตาราง |
| ภาพ 16:9 + คำบรรยาย | `img()` แทรกภาพกว้าง 15.00 ซม. (สูง 8.44 ซม.) พร้อมคำบรรยาย "ภาพที่ N ..." ใต้ภาพ |

เพิ่ม `updateFields = true` ใน `settings.xml` เพื่อให้ Word สร้างสารบัญให้เองตอนเปิดเอกสาร

## การตรวจสอบ

ตรวจไฟล์ .docx โดย unzip แล้วอ่าน XML

- `numPr`, `ListBullet`, `List Number` = **0 จุด** ทั้งเอกสาร
- `<w:color w:val=...>` มีเฉพาะ `000000` ไม่มีสีอื่นเลย
- shading fill มีเฉพาะ `E7E7E7` (หัวตาราง)
- ภาพทั้ง 33 ภาพ ขนาด 15.00 × 8.44 ซม. อัตราส่วน 1.778 เท่ากันหมด
- ไฟล์ .png ทั้ง 32 ไฟล์ ขนาด 3200×1800 อัตราส่วน 1.7778

ตรวจ PDF ที่ render ออกมาด้วยตา หน้า 1–8, 14–16, 21–23 — ปกอยู่หน้าเดียว ลำดับตัวเลขแสดงถูกต้อง หัวตารางเทาจัดกึ่งกลาง ภาพมีคำบรรยายครบ

**ยังไม่ได้ทดสอบ:** เปิดไฟล์ใน Microsoft Word จริง (ทดสอบผ่าน LibreOffice เท่านั้น) — ต้องยืนยันว่าสารบัญเติมเลขหน้าให้อัตโนมัติ
